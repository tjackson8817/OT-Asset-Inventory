Free OT / ICS Security Tool

OT Asset Inventory

A free command-line tool that turns a packet capture and an Nmap scan into a real asset inventory — every device, its likely vendor, its open ports and protocols, and its role on the network.

Download on GitHub Need help running an assessment?

What it does

  • Identifies device vendors via MAC address (OUI) lookup, extendable with your own database
  • Classifies each device's likely role: PLC/RTU, Engineering Workstation/HMI, Converged IT/OT Host, IT-only, or Unclassified
  • Tracks layer-2-only devices (PROFINET, EtherCAT, IEC 61850 GOOSE/SV) separately, since they have no IP address
  • Outputs a spreadsheet-ready CSV, plus JSON, Markdown, and PDF

Built for

OT / ICS Engineers

Build a real asset list from your own network traffic instead of starting from a blank spreadsheet.

Security Analysts

Know what's actually on the network -- vendor, role, and protocol -- before you assess risk.

Consultants & Auditors

Hand a client a structured asset inventory as a starting point for a real audit, from a single command.

Free and open source. Requires Python 3.8+.
Disclaimer: Role classification and vendor identification are heuristic starting points, not certified device-identity determinations — verify against your own asset records before acting on them.
